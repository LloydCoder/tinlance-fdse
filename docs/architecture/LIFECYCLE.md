# FDSE lifecycle

Customer -> Project -> Repository/System -> Assessment -> Engineering Context -> Findings -> Evidence -> Engineering Plan -> Governed Agent Execution -> Changes -> Tests -> Verification -> Human Approval -> Remediation -> Final Evidence -> Report.

FDSE creates and validates engineering-domain objects. The Agent Platform authorizes consequential execution. A production execution context must bind tenant, project, repository revision, requested role, objective, risk classification, and approval requirements.

A remediation is not complete because a patch was generated. It becomes complete only after tests and security verification succeed and required human or policy approval is recorded.
