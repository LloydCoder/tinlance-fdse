## Security and trust-boundary audit

The repository consistently preserves the governing invariant:

> **FDSE owns engineering semantics; Tinlance Agent Platform owns generic agent authority and execution infrastructure.**

FDSE does not mint authentication, authorization, approval, capability-grant, cryptographic-signing, sandbox, model-access, deployment, or external-production authority. Consequential execution intent remains subject to the external Agent Platform governance boundary.

Customer repository content, model output, tool output, dependency metadata, build output, and external service responses remain untrusted inputs. The domain layer cannot elevate those inputs into authority.
