# TSIC integration

FDSE consumes canonical TSIC integration contracts while retaining authority over engineering-delivery and transformation-domain semantics.

- **TSIC** owns ecosystem integration and certification.
- **FDSE** owns engagement semantics, delivery workflows, evidence, outcomes, and route selection.
- **Engineering** and **Transformation** are first-class, explicit routes and must not be conflated.
- **Agent Platform** owns consequential execution authority.

The acquisition handoff is a canonical `EngineeringOpportunity`/delivery intent carrying tenant, account, signal, evidence, technical/business hypothesis, confidence, urgency and explicit `delivery_route`.

The conformance gate verifies the shared identity, event, delivery, trace and economic-attribution contracts and the route/authority invariants.
