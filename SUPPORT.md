# Support

## Before asking for help

1. Read the [README](README.md).
2. Search existing GitHub issues.
3. Check the architecture documentation in [docs/architecture](docs/architecture/).
4. Reproduce the problem with the smallest possible example.

## Where to ask

| Need | Channel |
|---|---|
| Bug or reproducible defect | [GitHub Issues](https://github.com/LloydCoder/tinlance-fdse/issues) |
| Feature proposal | [GitHub Issues](https://github.com/LloydCoder/tinlance-fdse/issues) |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private reporting only |
| Contribution guidance | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Architecture question | Start with [BOUNDARY.md](docs/architecture/BOUNDARY.md) and open an issue if clarification is still needed |

## What to include

When requesting help, provide:

- FDSE version or commit;
- Python version and operating system;
- minimal reproduction;
- exact command or code used;
- complete error message or traceback with secrets removed;
- expected versus observed behavior.

Do not post credentials, API keys, customer source code, private repository contents, or vulnerability details publicly.
